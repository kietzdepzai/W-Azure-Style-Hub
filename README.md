# W-Azure Style Hub

Custom Blox Fruits script inspired by W-Azure Hub.

## Features
- Auto Farm
- Bring Mob (Gom quái)
- Kill Aura
- WalkSpeed / JumpPower

## How to use
1. Copy content of [`script.lua`](script.lua)
2. Paste into your executor (Delta, Wave, Fluxus...)
3. Execute
4. Bật **Gom Quái** trước, sau đó bật **Auto Farm**

## Note
This is a basic custom version. Not affiliated with the original W-Azure Hub.
Use at your own risk. Game updates may break the script.
